# 简单记账（Simple Accounting）

**Version 1.0.0**

> 记录每一笔收支，看清每一分去向

> **个人项目 / Personal Project**

## 项目介绍

简单记账是一个前后端分离的记账应用，用于记录日常收支、管理分类、按时间查看账单。项目完整走通了「前端 → 接口 → 数据」全链路，覆盖登录鉴权、账单增删改查、分类管理与月度统计等核心场景。

## 个人项目

这是一个由个人独立完成的练习项目：从需求设想、页面设计到接口与数据库设计均为亲手实现，没有团队协作，也不以商业化为目标。代码与功能会随学习进度持续调整，欢迎交流与指正。

## 主要功能

- **收支记录**：新增、编辑、删除与查询账单，记录金额、类别、时间与备注
- **分类管理**：支出 / 收入各自维护类别，支持自定义名称与图标
- **按月筛选**：按月份查看账单列表，快速回顾每笔开销
- **数据概览**：汇总每月收入、支出与结余
- **登录鉴权**：token 校验，401 自动清理登录态并跳转登录页

## 一些实现细节

- **统一响应体**：后端返回 `{ code, message, data }`，前端在 axios 拦截器中统一处理业务码与错误提示。
- **登录态**：请求拦截器自动携带 token；响应 401 时清理本地登录态并跳转登录页。
- **类型安全**：枚举用 `as const` 定义，配合类型守卫（如 `checkIsCategoryType`）在运行时校验来自 URL / state 的参数，避免隐式转换带来的误判。
- **路由传参**：需要刷新保留、可分享的参数走 query；页间临时对象走 `state`，并在接收处做类型收窄。
